# MERN Stack Full Course Codes

This repository contains foundational code examples and practice projects 
for learning the MERN stack. It starts with **HTML, CSS, and JavaScript** basics 
to build strong frontend skills before moving to React, Node.js, Express, and MongoDB.

---

## Folder Structure
- **03js/** → JavaScript practice codes
- **CSS/** → Styling examples
- **File path/** → Path handling practice
- **HTML FORMS/** → Form elements and validation
- **list/** → Ordered & unordered lists
- **projects/** → Mini frontend projects
- **Table/** → Table formatting and examples
